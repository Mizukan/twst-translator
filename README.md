# Fairy Bell

**《扭曲仙境》（ディズニー ツイステッドワンダーランド）的非官方剧情翻译器。**

游戏里显示日文对话时，**悬浮窗只把中文译文贴出来** —— 看游戏本体就行。
不机翻、不联网、鼠标穿透，不挡操作；也不改游戏、不解包、不注入，只是"在旁边显示一行中文"。

> 本项目**不分发游戏本体、资源包或任何游戏素材**，只提供译文表和显示工具。
> 《扭曲仙境》版权归 Aniplex / f4samurai 所有，请支持正版。

## 下载

- **GitHub**（推荐）：[Releases 页面](https://github.com/Mizukan/twst-translator/releases) —— 下载最新那个 `twst-translator.zip`
- **夸克网盘**：[点这里](https://pan.quark.cn/s/e7c872dfdb60?pwd=khYh)　提取码 `khYh`（国内下载更快）
- 系统要求：Windows 10 / 11（64 位）
- 解压到任意目录，双击 `Fairy Bell.exe` 就能用（绿色版，不用安装）

## 怎么用（三步）

1. 双击 `Fairy Bell.exe`，把游戏窗口摆好（BlueStacks 窗口或全屏都行）
2. 点 **框选文字区**，把对话框里的日文圈起来
3. 在 **主角名** 那一栏填上你在游戏里起的名字，然后点 **开始翻译**

> **第 3 步别跳过。** 游戏里主角的名字是玩家自己起的，剧本里写的是占位符；
> 不填的话，那些地方会原样显示成 `[HERO_NAME]`。

之后悬浮窗会一直跟着剧情走，**不用再管**。

## 有什么功能

- **只显示中文**：悬浮窗上干干净净，不挡着看游戏
- **一句不漏**：对话框同时出现两三句时，按顺序全部显示
- **鼠标穿透**：点在悬浮窗上，点击会落到下面的游戏里
- **样式随便调**：字号、字体、文字色、不透明度、描边、阴影、背景色/透明度
- **临时框选翻译**：按 `Ctrl+Alt+X` 框住屏幕任意一块（选项、提示），译文出现在旁边，几秒后消失
- **章节锁定**：只在你当前看的那一节译文里查，别的章节里"开头一样"的句子不会串进来
- **译文自动更新**：点界面上的 **译文更新** → 检查更新 → 一键装上新译文，**不用重下程序**

热键：`Ctrl+Alt+H` 显示/隐藏悬浮窗 ｜ `W` 调位置 ｜ `R` 开始/停止 ｜ `X` 临时框选 ｜ `Q` 退出
（都能在 `config.json` 里改）

## 常见问题

| 情况 | 怎么办 |
| --- | --- |
| 杀毒软件报毒 / 拦住了 | exe 没做数字签名，加信任或放行即可 |
| 译文里出现 `[HERO_NAME]` | 界面上的「主角名」没填，填上你在游戏里起的名字 |
| 游戏切全屏独占时悬浮窗被盖住 | 换成窗口 / 无边框模式（BlueStacks 默认就没事） |
| 换了分辨率或窗口大小后识别不准 | 点「框选文字区」重新圈一次 |
| 提示「（这句还没有译文）」 | 这句还没翻，或者不在当前这一节里 |
| 没联网 | 照样能用（查表是本地的）；只有「译文更新」需要网 |
| 想自己改某句译文 | 打开 `data\` 里的 csv 改，重开程序生效 —— 注意**别动表头、另存为 CSV UTF-8**（详见下面「关于译文」） |

## 关于译文

- 覆盖**主线 / 活动 / 卡面**三张表，约 17 万句
- **由于文字量庞大，目前只通过 AI 机翻和个人粗略校对，如果有翻译问题欢迎反馈**
- **角色中文名来自简中官方画集、以及简中官方漫画中已提及的角色；未提及的目前皆为自翻，后续根据官方版本更新**

### 想自己改几句译文？

`data\` 里的 csv 可以直接用 Excel / WPS 打开改，重开程序就生效。但要注意两条：

1. **别动第一行的表头**（`jp,zh,speaker_jp,speaker_zh,type,source`）—— 表头被改掉，程序就认不出这张表了
2. 改完另存为 **CSV UTF-8** 编码 —— 存成别的编码（或者被 Excel 存成 GBK），中文可能变乱码

弄错的典型症状是：重开程序后界面上的「译文表 N 条」明显变小，或者日志里出现
「⚠ 这个文件没能读进去」。真改坏了也不怕，重新下载一次译文就行（点程序里的「译文更新」）。
