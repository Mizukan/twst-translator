# Fairy Bell v2.0

**《扭曲仙境》（ディズニー ツイステッドワンダーランド）的非官方剧情翻译器。**

游戏显示日文对话时，Fairy Bell 会识别对话框里的文字，从整理好的中文译文表中查找对应内容，再把中文悬浮显示在游戏上。

它不是机翻器，不会修改游戏，也不会显示日文原文。悬浮窗鼠标穿透，点击仍会落到游戏里，不挡操作。

系统要求：**Windows 10 / 11 64 位**。解压后双击 `Fairy Bell.exe` 即可使用，不需要安装。

> 安装主线、活动和卡面三张译文表。装好后不用重启。

## v2.0 更新内容

- **简洁模式成为默认界面**：启动后只显示悬浮译文和顶部快捷栏；开始、停止、框选、临时、设置、收起和退出都在快捷栏里。
- **快捷栏可移动、可收起**：平时不占屏，需要调整时再打开完整设置。
- **临时框选按钮**：快捷栏可直接进入临时框选；选项、系统提示和其他位置文字都能临时查看。
- **启动提示精简**：欢迎框只保留作者、三步使用提示、使用说明路径、通知 QQ 群和关于软件入口，长链接集中到「关于软件」。
- **名字牌识别增强**：支持位置较低的名字牌、带感叹号的正文和 `リリア・トレイ` 等双人名字牌。
- **短句匹配增强**：大量同名短句会优先按说话人筛选；小假名、促音和长音被 OCR 读错时也会继续查找相邻台词。
- **同框连续台词补全**：同一个台词框里连续追加的几段文字会一起显示，不再只显示第一段。
- **OCR 稳定性增强**：识别区边缘容易导致长句被截断，v2.0 增加了留白和短文本自动重试。
- **自动跟章继续增强**：优先在当前章节查找，认出其他章节的明确台词后再自动切换。

## 功能

- **只显示中文**，不显示角色名和日文原文
- **鼠标穿透**，不影响游戏操作
- **自动跟随章节**，无需手动选择
- **多行台词一起显示**
- **临时框选翻译**：`Ctrl+Alt+X`
- **译文表选择**：主线 / 活动 / 卡面 / 全部
- **主角名替换**：支持 `[HERO_NAME]` 占位符
- **显示样式自定义**：字号、字体、颜色、透明度、背景、描边和阴影
- **译文一键更新**：只下载变化的表，不需要重新安装程序
- **OBS 窗口采集**：可以直接录制透明悬浮窗
- **低资源占用**：画面不变时跳过 OCR，并限制 OCR 线程数

## 第一次使用

1. 解压完整程序文件夹。`Fairy Bell.exe` 和 `_internal\` 必须放在一起。
2. 打开后进入「译文更新」，检查并安装最新的三张译文表。
3. 回到「基本」页，点「框选文字区」：
   - 把对话框里的日文一起框进去；
   - **也把左上角角色名字牌一起框进去**；
   - 名字牌只辅助匹配，不会显示在译文里。
4. 填写你在游戏里使用的主角名。否则译文里可能出现 `[HERO_NAME]`。
5. 选择当前要看的表，回到简洁快捷栏点「开始」。

## 临时框选

游戏选项或系统提示不在对话框里时：

1. 按 `Ctrl+Alt+X`，或点快捷栏里的「临时」；
2. 框住需要查看的文字，两个选项可以一次框住；
3. 译文会显示在选区附近，几秒后自动消失。

临时译文的位置可以固定，也可以在设置里调整显示时长。

## 热键

| 热键 | 功能 |
| --- | --- |
| `Ctrl+Alt+H` | 显示 / 隐藏悬浮译文和快捷栏 |
| `Ctrl+Alt+W` | 调整悬浮窗位置 |
| `Ctrl+Alt+R` | 开始 / 停止识别 |
| `Ctrl+Alt+X` | 临时框选翻译 |
| `Ctrl+Alt+Q` | 退出程序 |

热键可以在 `config.json` 中修改。

## 译文更新

程序更新和译文更新是分开的。

- 新剧情只需要更新译文表，不用重新下载程序；
- 进入「译文更新」，点「检查更新」；
- 只下载有变化的表，装好不用重启；
- 译文发布源优先使用码云；
- 也可以从 zip 文件手动安装译文包。

[查看译文更新日志](https://gitee.com/minasami/twst-translator/blob/main/CHANGELOG.md)

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 首次打开显示“这句还没有译文” | 先安装译文表 |
| 译文里出现 `[HERO_NAME]` | 在「基本」页填写游戏主角名 |
| 换了分辨率或游戏窗口后识别不准 | 重新框选文字区 |
| 短句匹配到其他角色 | 框选时把角色名字牌一起框入 |
| 游戏独占全屏时悬浮窗被盖住 | 改用窗口或无边框模式 |
| OBS 抓不到或抓到花屏 | 使用窗口采集的「Windows 10 (1903或更新版本)」方式 |
| 杀毒软件拦截 | 程序未做数字签名，请自行判断并加信任 |
